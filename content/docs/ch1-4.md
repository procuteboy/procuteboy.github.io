这部分内容主要介绍了弦理论中从点粒子到弦的基本概念、相关作用量、对称性以及运动方程和约束条件，具体如下：
1. **基本概念**：弦理论将一维扩展弦视为基本对象，与点粒子不同，弦在时空中扫出(1 + 1)维的世界面，而非世界线。世界面由固有时间\(\tau\)和空间坐标\(\sigma\)（\(\sigma\in[0,\sigma_0]\)  ）参数化，其嵌入目标时空（假设为D维闵可夫斯基时空，度规为\(\eta_{MN}\)  ）的过程由函数\(X^M(\tau, \sigma)\)描述，存在闭弦（世界面为圆柱面）和开弦（世界面为带状）两种类型。
2. **Nambu–Goto作用量**：描述弦的最简单的参数化不变作用量是Nambu - Goto作用量：
\[S_{NG} = -\frac{1}{2\pi\alpha'} \int_{\Sigma} d^2\sigma \sqrt{-\det(\partial_{\alpha}X^M\partial_{\beta}X^N\eta_{MN})}\]
其中\(d^2\sigma = d\sigma^0d\sigma^1\) ，\((\sigma^0, \sigma^1) \equiv (\tau, \sigma)\)，\(\alpha'\)与弦长\(l_s\)的关系是\(\alpha' = l_s^2\)，\(\tau_F = \frac{1}{2\pi\alpha'}\)被称为基本弦的张力。但该作用量因含有平方根，处理起来困难，对其描述的理论进行量子化也很复杂。
3. **Polyakov作用量**：为简化研究，引入世界面度规\(h_{\alpha\beta}(\sigma)\)作为辅助场，得到Polyakov作用量：
\[S_P = -\frac{1}{4\pi\alpha'} \int_{\Sigma} d^2\sigma \sqrt{-h} h^{\alpha\beta} \partial_{\alpha}X^M \partial_{\beta}X^N \eta_{MN}\]
其中\(h = \det(h_{\alpha\beta})\)，\(h^{\alpha\beta}\)是\(h_{\alpha\beta}\)的逆矩阵。由\(\delta S_P / \delta h_{\alpha\beta} = 0\)可得世界面能量 - 动量张量\(T_{\alpha\beta} = 0\)，这一约束条件被称为Virasoro约束。该约束可消除Polyakov作用量中的世界面度规，从而得到Nambu - Goto作用量，表明两个作用量在经典层面等价。由于Polyakov作用量更便于对理论进行量子化，后续研究多基于此。
4. **Polyakov作用量的对称性**
    - **D维庞加莱变换**：作用量在\(X^M \to X'^M = \Lambda^M_N X^N + a^M\)（\(\Lambda^M_N\)为洛伦兹变换，\(a^M\)为时空平移）且\(\delta h_{\alpha\beta} = 0\)的变换下保持不变。
    - **世界面重参数化**：在\(\sigma^{\alpha} \to \sigma'^{\alpha} = f^{\alpha}(\sigma)\)的重参数化下，\(h_{\alpha\beta}(\tau, \sigma)\)和\(X^M(\tau, \sigma)\)按\(h_{\alpha\beta}(\tau, \sigma) = \frac{\partial f^{\gamma}}{\partial \sigma^{\alpha}} \frac{\partial f^{\delta}}{\partial \sigma^{\beta}} h_{\gamma\delta}(\tau', \sigma')\)和\(X'^M(\tau', \sigma') = X^M(\tau, \sigma)\)变换，作用量不变。
    - **外尔变换**：当\(h_{\alpha\beta}(\tau, \sigma) \to e^{2\omega(\tau, \sigma)} h_{\alpha\beta}(\tau, \sigma)\)且\(X'^M(\tau, \sigma) = X^M(\tau, \sigma)\)时，作用量保持不变。
5. **共形规范及相关方程**：利用这些局部对称性，选择共形规范\(h_{\alpha\beta} = e^{2\omega(\tau, \sigma)} \eta_{\alpha\beta}\)（\(\eta_{\alpha\beta} = \begin{pmatrix}-1 & 0 \\ 0 & 1\end{pmatrix}\)  ），此时Polyakov作用量变为：
\[S_P = \frac{1}{4\pi\alpha'} \int d^2\sigma (\partial_{\tau}X^M \partial_{\tau}X^N - \partial_{\sigma}X^M \partial_{\sigma}X^N) \eta_{MN}\]
\(X^M(\tau, \sigma)\)的运动方程为相对论波动方程\((\partial^2_{\tau} - \partial^2_{\sigma})X^M = \partial_+\partial_-X^M = 0\)（其中引入了光锥坐标\(\sigma^{\pm} = \tau \pm \sigma\)及相应导数\(\partial_{\pm} = \partial / \partial\sigma^{\pm}\) ），还需补充边界条件\(\partial_{\sigma}X^M \delta X^M |_0^{\sigma_0} = 0\)以及Virasoro约束条件（在共形规范下为\(T_{++} = \partial_+X^M \partial_+X^M = 0\)，\(T_{--} = \partial_-X^M \partial_-X^M = 0\)，\(T_{+-} = T_{-+} = 0\) ） 。
